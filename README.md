## 🚀 Highlighted Engineering Portfolio

### 🎮 Custom 2D Kinematic Physics Engine (`tile-platformer-game`)
An architecture-focused 2D side-scrolling platformer engine engineered completely from scratch without commercial game builders.
- **Euler Integration:** Modeled physical particle vectors managing real-world kinematic forces (gravity velocity integration over time).
- **Axis-Separated AABB Resolution:** Engineered an intentional axis separation pipeline to resolve environmental intersections separately, eliminating multi-jump exploits and corner-clipping bugs.
- **$O(1)$ Spatial Matrix Indexing:** Optimized world collision lookups by mapping the environment array to a rigid 2D grid matrix, replacing unoptimized $O(N)$ brute-force calculations with a constant time complexity check.
- **State-Driven Animation Manager:** Structured a time-quantized finite state machine (`IDLE`, `RUNNING`, `JUMPING`) rendering mirrored pixel arrays on-the-fly via coordinate reflection buffers.

### 📦 Local E-Commerce Automation Backend (`local-ecommerce-backend`)
A data-driven store management core engineered to handle automated local commerce transactions securely.
- Developed a modular, lightweight Python-driven transaction processing structure.
- Designed schema relationships and implemented stable data persistence channels using SQLite.
- Standardized robust input error validation protocols to secure storage records against transaction conflicts.

### 🗺️ Trot — Collaborative City Tour Guide Platform (`Trot`)
A user-friendly, cross-platform mobile itinerary tracking application designed for international city exploration.
- **Team-Driven Development:** Engineered in an agile, 3-person engineering sprint, focusing on version control discipline and module integration.
- **Cross-Platform Delivery:** Designed front-end responsive views and modular widget tree states utilizing Dart and the Flutter framework.
- **State Optimization:** Implemented UI flow architectures to parse travel location indices dynamically.
